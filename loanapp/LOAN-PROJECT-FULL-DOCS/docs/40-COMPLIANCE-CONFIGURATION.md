# 40 — Compliance Configuration

## Purpose
Keep jurisdiction/lender-specific legal and compliance requirements configurable and explicitly approved.

## Items requiring lender/compliance confirmation
- KYC process
- bureau consent
- privacy consent
- KFS format/content
- APR/interest disclosures
- fee/tax disclosures
- agreement/e-sign process
- grievance/contact information
- cancellation/withdrawal rules
- data retention/deletion
- repayment disclosures
- disbursement controls
- notification wording

## Rule
Antigravity must not invent compliance language. Implement placeholders/templates/configuration until approved content is provided.
