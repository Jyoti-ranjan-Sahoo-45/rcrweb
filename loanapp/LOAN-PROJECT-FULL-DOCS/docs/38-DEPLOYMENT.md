# 38 — Deployment

## Components
React frontend, Laravel backend, database, private storage, queue worker, scheduler, Android release.

## Backend checklist
HTTPS, env secrets, migrations, queue, scheduler, private storage, logs/monitoring, backup, optimized production config.

## Frontend
production API URL, production build, no debug screens, mobile QA.

## Android
release signing, production origin, target/build settings, icon/splash, WebView debug off, allowlist, production push config, deep links, real-device test.

## Release rule
No breaking DB change without migration and rollback planning.
