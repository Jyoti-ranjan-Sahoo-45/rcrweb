# 20 — Notification Rules

## Channels
In-app, push, email, SMS, WhatsApp when configured and permitted.

## Events
account created, application submitted, document rejected, replacement requested, information requested, assessment update if customer-facing, approved, rejected, offer issued, offer expiring, offer accepted, formal document available, payment created/success/failed, ready for disbursement, disbursement initiated/completed.

## Data
event type, recipient, channel, template, state, provider reference, failure reason, timestamps.

## Privacy
Push notification text must avoid unnecessary sensitive loan data on lock screen.

## Deep links
Notification navigation must still enforce authentication and ownership.
