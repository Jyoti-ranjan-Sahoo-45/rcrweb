# 25 — Search, Filter, Sort and Pagination

## Admin lists
Server-side pagination/search/filter/sort.

## Application search
Application number, customer name, mobile, email.

## Filters
status, category, product, assigned user, submitted date, amount range, document status, offer status, payment status, disbursement status.

## Sort
newest, oldest, updated, amount, customer name.

## Response metadata
current_page, per_page, total, last_page, items.

Set a safe maximum page size.

## Customer
Use mobile cards and lightweight pagination/infinite loading only when needed.
