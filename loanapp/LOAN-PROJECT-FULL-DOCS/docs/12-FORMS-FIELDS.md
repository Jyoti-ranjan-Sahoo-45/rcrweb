# 12 — Forms and Fields

## Registration
full_name, mobile, email, verification input when applicable, password/secure method, customer_type, consent.

## Personal
first_name, middle_name optional, last_name, DOB, gender only if required, mobile, alternate mobile optional, email, current/permanent address, city/state/postal code, residency info where required.

## Identity
Use only approved KYC identity fields. Do not collect unnecessary identity data.

## Salaried
employer_name, employment_type, designation, employment duration/start date, office address, monthly income, salary-credit info if required, obligations.

## Business
business_name, business_type, registration details if applicable, address, industry, vintage, annual turnover, monthly sales where needed, employee count optional, existing loans, loan purpose.

## Financial
monthly income, monthly expenses, annual income/turnover, existing EMI, existing obligations, requested amount, requested tenure, purpose.

## Banking
Only if required: bank name, account holder, account type, approved account identifier fields, branch/IFSC or equivalent.

## Offer
approved amount, interest/rate description, tenure, EMI, processing fee, tax, other charges, conditions, validity.

## Disbursement
gross amount, allowed deductions, net amount, destination reference, transaction reference, timestamps.

## Rule
Document which fields are customer-editable, customer-view-only and admin-only.
