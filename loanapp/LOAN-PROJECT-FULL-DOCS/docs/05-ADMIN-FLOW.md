# 05 — Admin Flow

## Intake
Submitted application → queue → assignment → completeness check.

## Verification
Review details/documents → verify/reject/request replacement → request additional information if needed.

## Assessment
Once information is sufficient → eligibility/internal review → credit assessment → recommendation.

## Decision
Authorized approver:
- approve
- reject
- request more information
- return for reassessment

Every decision records actor, timestamp, reason/comment where required and resulting status.

## Offer
Approved → prepare offer → amount/rate/tenure/EMI/fees/taxes/conditions/validity → preview → issue.

## Customer response
Accepted → formalities.
Declined → closed/declined path.
Expired → expiry path and controlled reissue if permitted.

## Formalities
Track KFS/agreement/acknowledgements and pre-disbursement conditions.

## Payment
If applicable → payable item → provider result → backend verification → finance review where required.

## Disbursement
Checklist complete → ready → initiated → processing → disbursed.
Failure → failed/action required → controlled retry.

## Closure
Historical application and audit trail remain available according to policy.
