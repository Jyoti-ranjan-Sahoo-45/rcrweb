# 02 — Project Scope

## V1 customer scope
- registration and authentication
- profile
- loan category/product discovery
- eligibility form
- draft application
- multi-step application
- save/resume
- document checklist/upload/re-upload
- application submission
- unique application number
- status timeline
- action-required requests
- offer review/accept/decline
- KFS/agreement/formality viewing
- applicable fee payment
- payment status
- disbursement status
- notification center
- downloads

## V1 admin scope
- admin authentication
- dashboard
- application queues
- application details
- search/filter/sort/pagination
- assignment
- document verification
- information requests
- eligibility/credit assessment
- approval/rejection
- offer creation/issue
- formalities tracking
- payment verification
- disbursement workflow
- product configuration
- users/roles/permissions
- reports
- audit logs

## V1 Android scope
- branded app icon/splash
- secure WebView/customer portal host
- back-button behavior
- camera/document picker
- downloads
- connectivity states
- notifications/deep links
- external URL policy
- payment return handling

## Out of scope unless later approved
- iOS app
- full post-disbursement loan servicing
- EMI collection/collections engine
- AI underwriting
- automatic credit decisioning
- automatic bank-statement analysis
- multi-lender marketplace
- accounting ERP
- core banking replacement
- automatic legal text generation

## Scope control
Undocumented features may be proposed, but must not silently become required dependencies.
