# 04 — Customer Flow

## Entry
Android app or customer website.
Authenticated → Dashboard.
Unauthenticated → Login/Register.

## Registration
Enter identity/contact details → verification if configured → consent → account created → dashboard.

## Product discovery
Dashboard → categories → product → product details → eligibility.

## Eligibility
Collect basic criteria. Result:
- may proceed
- needs more information
- basic criteria not met

Eligibility result is not loan approval.

## Application
Create draft → personal → employment/business → financial → banking where required → loan request → documents → declarations → review → submit.

Allow save/resume before submission.

## Submission
Backend validates complete application, freezes protected submitted data as required, creates application number, writes status history, sends confirmation.

## During review
Customer sees a simplified timeline and any `Action Required` request.

## Information request
Open request → read requirement → add response/upload document → submit response → status returns to correct review step.

## Offer
Offer available → review approved amount, rate, tenure, EMI, fees/taxes/charges, conditions and validity → accept or decline.

## Formalities
After acceptance → view required KFS/agreement/approved documents → acknowledge/sign through configured process.

## Payment
Where applicable → view amount → start payment → return → show processing/success/failure based on backend verification.

## Disbursement
Ready → processing → disbursed → customer receives confirmation and permitted documents.
