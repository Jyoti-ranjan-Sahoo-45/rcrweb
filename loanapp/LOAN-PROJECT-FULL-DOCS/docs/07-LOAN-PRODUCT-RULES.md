# 07 — Loan Product Rules

## Hierarchy
Loan Category → Loan Product.

## Configurable product properties
- code/name
- description
- active state
- supported customer type
- min/max amount
- min/max tenure
- indicative pricing text
- required application sections
- required documents
- eligibility questions/rules
- applicable fee rules
- offer validity default
- formal document/template references

## Example categories
Personal, Business, MSME, Working Capital, Professional, Vehicle, Education, Property-related.

## Eligibility examples
- age
- employment type
- income
- turnover
- business vintage
- location
- requested amount
- obligations

## Versioning
Historical applications must retain the product configuration/commercial context applicable when submitted/offered. Later product edits must not rewrite past records.
