# 26 — Reports and Dashboard

## Dashboard KPIs
applications received, in review, action required, assessment, approval pending, approved, rejected, offers awaiting response, payment pending, ready for disbursement, disbursed count/value, pending disbursement value.

## Reports
- applications by date/category/product
- requested/approved/disbursed amounts
- approval/rejection counts
- offer acceptance
- customer drop-off
- document rejection/re-upload
- processing turnaround
- staff queue/workload

## Rules
Each KPI needs one documented query definition. Report exports require permission and sensitive-data controls.
