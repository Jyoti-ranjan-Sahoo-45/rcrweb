# 11 — UI/UX Design System

## Personality
Trustworthy, professional, simple, calm, clean.

## Design tokens
Define centrally:
- primary/secondary brand colors
- success/warning/error/info
- neutral palette
- typography scale
- spacing scale
- radius scale
- input/button heights
- shadows/elevation
- breakpoints

## Customer UI
Mobile-first, readable, touch-friendly, clear next action.

Avoid:
- excessive gradients
- dense cards
- decorative clutter
- tiny text
- hidden terms
- desktop-style tables

## Admin UI
Higher information density is acceptable:
- searchable/filterable tables
- status chips
- consistent action placement
- clear queue indicators

## Accessibility
- sufficient contrast
- visible focus
- semantic labels
- keyboard support for admin web
- errors not communicated by color alone
