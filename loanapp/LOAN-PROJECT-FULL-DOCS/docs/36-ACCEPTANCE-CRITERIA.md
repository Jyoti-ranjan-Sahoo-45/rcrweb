# 36 — Acceptance Criteria

## Customer complete
Register/login, product discovery, eligibility, draft/save/resume, valid submission, document flow, timeline/action required, offer, formalities, payment, disbursement, responsive mobile UI, safe error states.

## Admin complete
Permissions, dashboard, application queues, search/filter/sort/page, details, assignment, verification, information request, assessment, decision, offer, payment verification, disbursement, audit, product/user management, reports.

## Android complete
Branded launch, reliable portal, correct back behavior, file/camera/download, offline state, notifications/deep links, payment return, safe WebView, production environment.

## Backend complete
Validated APIs, centralized transitions, permission enforcement, private files, audit trail, critical automated tests.
