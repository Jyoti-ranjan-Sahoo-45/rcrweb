# 17 — KFS, Agreement and Formalities

## Purpose
Manage approved loan disclosures, KFS, agreement and required acknowledgements.

## Compliance rule
Exact content and signing/acknowledgement process must come from approved lender/legal/compliance requirements. Do not invent legal wording.

## Record
- application
- document/formality type
- template version
- generated/sent timestamp
- viewed timestamp where needed
- accepted/signed timestamp
- provider reference where external signing is used
- status

## States
pending, generated, available, viewed, accepted/signed, failed, superseded.

## Disbursement rule
Configured mandatory formalities must complete before ready-for-disbursement.
