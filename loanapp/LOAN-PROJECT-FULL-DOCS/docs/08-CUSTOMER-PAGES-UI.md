## Dashboard order
1. Active application.
2. Action required.
3. Current status/timeline.
4. Primary next action.
5. Notifications.
6. Previous applications.

## Mobile rules
- cards, not desktop tables
- no horizontal scrolling
- large touch targets
- sticky primary CTA where helpful
- progress indicator
- field-level validation
- skeleton/loading states
- clear empty/error/retry states
- avoid browser-like navigation when embedded in Android

## Application screen
Header: back, section title, progress.
Body: focused fields and helper text.
Footer: Save & Continue / Back.
