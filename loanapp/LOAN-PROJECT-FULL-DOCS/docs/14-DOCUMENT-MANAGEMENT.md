# 14 — Document Management

## Lifecycle
Required → Uploaded → Under Review → Verified.
Alternate: Under Review → Rejected/Replacement Required → Re-upload → Under Review → Verified.

## Customer
- view checklist
- upload
- preview permitted own file
- replace when allowed
- see status
- see customer-safe rejection reason

## Admin
- secure preview
- verify
- reject
- request replacement
- request additional document
- internal note

## Versioning
Replacement creates a new version while preserving enough history to audit what was reviewed.

## Security
Private storage, authorized downloads, non-guessable keys, no filesystem path exposure, limited signed/temporary access where appropriate.
